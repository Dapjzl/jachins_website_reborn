Employee Accounts

Manage employee profiles. Admin-only — enforced both by this page's session check and by Row Level Security on the employees table itself.

Creating a new employee login is a two-step process:
  1. In your Supabase Dashboard → Authentication → Users → Add user, create the login with their work email + a temporary password. Copy the User UID shown after creation.
  2. Paste that User UID into the form below along with their profile details to link it to a directory entry.

This can't be done entirely from this page: creating Auth users requires Supabase's service_role key, which must never be present in frontend JavaScript (it bypasses Row Level Security entirely). A future improvement would be a small Supabase Edge Function that does step 1 server-side — not required for launch with ~20 employees.
